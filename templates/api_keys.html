How to Use the API

POST http://localhost:5001/api/digitize

Send an ECG image and receive all extracted data as JSON.

# cURL Example curl -X POST http://localhost:5001/api/digitize \ -H "X-API-Key: YOUR_API_KEY_HERE" \ -F "image=@/path/to/ecg.png"
# Python Example import requests url = "http://localhost:5001/api/digitize" headers = {"X-API-Key": "YOUR_API_KEY_HERE"} files = {"image": open("ecg.png", "rb")} response = requests.post(url, headers=headers, files=files) data = response.json() print(data)
